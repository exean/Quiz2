Schnellstart

Erzeuge einen API-Token im Dashboard (Sektion „API-Tokens") und schicke ihn als Authorization: Bearer …-Header mit. Alternative: nach einem POST /api/auth/login wird ein Session-Cookie gesetzt, das ebenfalls akzeptiert wird.

curl -H "Authorization: Bearer qzt_..." \
     https://deine-domain.tld/api/quizzes
